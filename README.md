# Medallion GTM Context OS

A structured GTM Context OS for [Medallion](https://medallion.co) — a provider operations platform serving telehealth, digital health, and healthcare staffing companies in the US.

Built as part of the Treford Africa GTM Engineering Cohort, Week 1.

## What this repo is
This repo holds Medallion's GTM context as plain text files, structured so Claude Code reads it every session. It contains research, ICP definitions, buying signals, system architecture, and outbound workflow specs.

## Structure
- `context/` — ICP, positioning, messaging, brand, and research
- `knowledge-base/` — GTM playbooks and learnings
- `output/campaigns/` — Workflow specs and campaign deliverables
- `tools/` — Tool notes and configuration
- `weekly-priorities/` — Weekly focus areas
- `work-log/` — Timestamped change log

## Reference
Built using the [PaidHR GTM OS](https://github.com/bolaji-ships/paidhr-gtm-os) as a structural reference.
